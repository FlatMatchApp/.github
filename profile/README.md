# FlatMatch

Trabajo práctico grupal de la materia Gestión de Sistemas de Información — FIUBA (Grupo 07).

Plataforma de búsqueda de inmuebles con matching personalizado: en vez de depender solo de filtros, construye un perfil de preferencias del usuario y recomienda propiedades mediante un sistema de matching con interacción rápida (estilo swipe), considerando además el entorno de cada inmueble (cercanía a transporte, servicios, parques, etc.) y recorridos virtuales 3D generados a partir de fotografías.
